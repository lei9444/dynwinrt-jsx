# Build a task Dashboard

This series starts from an empty directory and builds a native WinUI task
Dashboard with the recommended progressive API entry points.

The finished application includes:

- a typed reactive task model;
- NavigationView routing;
- keyed task collections;
- controlled input, dialogs, and theme switching;
- Host-owned persistence and validated Worker state;
- structured diagnostics and error boundaries;
- native validation and x64/ARM64 MSIX packaging.

The complete production-oriented reference remains
[`examples/dashboard`](../../examples/dashboard).

## Prerequisites

- Windows 11;
- Node.js 20 or later;
- the Windows development requirements used by `winapp`;
- the exact package versions generated by the project creator.
