# Minimal dynwinrt-jsx app

This starter keeps the production Host/Worker lifecycle while exposing only a
Counter model and three WinUI controls.

```powershell
npm install
npm run setup
npm start
```

Edit:

- `src/app-model.ts` for Signals and operations;
- `src/app.tsx` for the screen;
- `src/app-state.ts` for persisted/runtime schemas.

Use the dashboard template when routing, diagnostics, hot reload, themes, and
application-shell examples should be generated up front.
